- 🔹 **Arbitrary Keyword Arguments (`**kwargs`)\*\* – Passing dynamic key-value pairs
- 🔹 **Return Values** – Getting results from functions

## 📝 Example: Function with Arguments & Return Value

```python
def calculate_area(length, width):
    """Returns the area of a rectangle given its length and width."""
    return length * width

# Function call
area = calculate_area(10, 5)
print(f"The area of the rectangle is: {area}")
```

🔍 Explanation
calculate_area() is a function that accepts two parameters (length and width).
It calculates the area of a rectangle and returns the result.
The function is then called with values 10 and 5, and the output is printed.
