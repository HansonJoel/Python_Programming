# 🐍 Conditional Statements in Python

This repository contains examples and exercises on **conditional statements** in Python, covering `if`, `elif`, and `else` statements.

## 📌 Overview

Conditional statements allow a program to make decisions based on conditions. They are widely used in real-world applications like **form validations, data processing, automation**, and more.

## 📖 Concepts Covered

✅ **`if` Statement** – Executes a block of code if a condition is `True`.  
✅ **`elif` Statement** – Specifies multiple conditions when the first condition is `False`.  
✅ **`else` Statement** – Executes a block of code if all conditions are `False`.

## 🚀 Code Examples

### **Basic If-Else**

```python
age = int(input("Enter your age: "))

if age >= 18:
    print("You are eligible to vote.")
else:
    print("You are not eligible to vote.")
```

### ** Multiple Conditions with elif **

```python
score = int(input("Enter your test score: "))

if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
elif score >= 70:
    print("Grade: C")
else:
    print("Grade: F")
```
